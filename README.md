# Jiaolong AI

**Jiaolong** (蛟龙 in Chinese) is a **safe** and **privacy-focused** AI system built around the following principles:

- **Privacy-preserving**: Keep your data and interactions under your control.
- **Strict permission control**: Explicitly define what AI agents are allowed to access and do, with security enforced by design.
- **Manage agents, not processes**: Focus on what your AI agents should accomplish, rather than babysitting them through every step.
- **Task-driven execution**: Create a task and let the agent work autonomously until a commit is ready. No need to monitor intermediate results or track its progress.
